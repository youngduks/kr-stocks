## 1. 장면 함수의 계약

```js
const s3=(()=>{               // IIFE: 정적인 모양·난수는 여기서 한 번만 만든다
  const R=rng(33);            // 시드 고정 난수 → 매 프레임 같은 그림
  const parts=Array.from({length:40},()=>({x:R()*W,ph:R()}));
  return function(t,ts){      // 매 프레임 호출
    bg();                     // 배경 + 격자. 항상 먼저
    // t  : 장면 진행률 0→1 (d초 동안)
    // ts : 장면 시작 후 경과 초. 반복 운동(회전·거품·흐름)에 쓴다
  };})();
```

- 모양은 `t`의 함수로 결정해서 같은 `t`면 같은 그림이 나오게 한다. `Math.random()`은 불꽃처럼 깜빡여도 되는 장식에만 쓴다. 스크롤해서 되돌려도 장면이 맞아야 한다.
- 단계 전환 페이드(앞 0.35초)와 끝 페이드(마지막 0.3초)는 엔진이 처리한다. 단계별 정지는 `d-0.35`초에서 멈추므로 **그 시점의 화면이 그 단계의 완성 상태**여야 한다. 핵심 라벨은 `t≈0.85` 전에 모두 나타나게 한다.
- 첫 장면은 `t=0`에서도 비어 보이지 않게 한다(썸네일). 예: 이미 쌓인 원광 일부를 처음부터 그린다.
- 장면 길이 `d`는 9초가 기본이다. 자막 해설은 1–2문장(약 70–90자)으로 써서 음성 해설이 장면 안에 끝나게 한다. 길어지면 엔진이 최대 8초까지 기다린다.

## 2. 좌표계와 금지 구역

- 캔버스 논리 크기 **1280 × 720**(16:9). 화면 크기와 무관하게 이 좌표로 그린다.
- **HUD 구역:** 왼쪽 위(x 0–330, y 0–50)와 오른쪽 위(x 1060–1280, y 0–50)에 단계 라벨이 겹쳐 그려진다. 여기에는 글자를 두지 않는다. 장면 제목은 가운데 `y≈74–80`, 왼쪽 내용은 `y≥60`부터 쓴다.
- 아래쪽은 가리는 것이 없으므로 `y≤704`까지 쓸 수 있다.
- 휴대폰에서는 캔버스가 폭 약 360px로 줄어든다(약 0.28배). 캔버스 글자는 **15px 이상**, 핵심 라벨은 20–24px로 쓴다.
- 글자 폭 어림: 한글 1자 ≈ 글자 크기(px), 영문·숫자 ≈ 0.55배. 16px 한글 30자 ≈ 480px. 캔버스 텍스트는 자동 줄바꿈이 없으니 줄을 직접 나눈다.

## 3. 헬퍼 API (템플릿에 들어 있음)

| 이름 | 용도 |
|---|---|
| `W, H, TAU` | 1280, 720, 2π |
| `C` | 색 팔레트: `bg ink dim faint lilac copper copperD steel amber tan cyan N S grid` |
| `FB, FM, FD` | 본문 / 고정폭 / 제목(세리프) 글꼴 문자열 |
| `clamp(v,a,b) lerp(a,b,t)` | 기본 수학 |
| `seg(t,a,b)` | t가 a→b 구간일 때 0→1. 등장·전환 타이밍의 핵심 |
| `ease(t) eout(t)` | 가속·감속 곡선 |
| `rng(seed)` | 시드 고정 난수 함수 |
| `mixc(hexA,hexB,t,alpha)` | 두 색 보간 → rgba 문자열 (온도에 따른 발광 등) |
| `rr(x,y,w,h,r)` `poly(pts)` `circle(x,y,r)` `hexPath(x,y,r)` | 경로 만들기 (뒤에 `ctx.fill()`/`stroke()`) |
| `txt(s,x,y,{s,w,c,al,a,mono,font})` | 글자. `s` 크기, `w` 굵기, `al` 'left'·'center'·'right', `a` 투명도 |
| `tag(s,x,y,{s,al,c,tc,mono,a})` | 테두리 있는 알약형 라벨 (단계 칩, 온도 표시) |
| `callout(px,py,lx,ly,title,sub,a,col)` | 점 → 지시선 → 제목+부제. `lx≥px`면 글자가 오른쪽, 아니면 왼쪽으로 정렬 |
| `arrow(x1,y1,x2,y2,{c,w,a,dash,head})` | 화살표 |
| `rockShape(R,n)` `drawRock(x,y,r,rot,shape,col,speck)` | 광석·덩어리 |
| `mound(cx,baseY,halfW,h,fill,dotColor,seed)` | 분말 더미 (높이를 t로 키우면 쌓이는 연출) |
| `metalGrad(x0,y0,x1,y1)` | 금속 광택 그라디언트 |
| `pathLen(pts)` `along(pts,L,u)` | 경로를 따라 이동 (컨베이어, 배관 흐름) |
| `bg()` | 배경과 격자 |
| `coilFace(x,y,R,r,col)` | 코일을 축 방향에서 본 모습(감긴 층 링). 반지름 R을 t로 키우면 권취, 줄이면 권출 |
| `rollC(x,y,r,ang,col)` | 회전하는 롤(압연롤, 이송 롤, 지지 롤). `ang`에 `ts*속도`를 넣는다 |
| `heat(u)` | 온도색: u 0(고온, 밝은 주황) → 1(식은 회색). 주편·열연 판처럼 공정을 따라 식는 물체 |
| `cylStack(x,y,rx,h,col,face)` | 원통 적층체(코어 스택, 코일 측면). 옆면에 층 선을 긋고, `face()`가 윗면을 위에서 본 좌표(원점 중심)로 그리면 납작하게 눌러 얹는다 |

`ctx`는 이미 1280×720 좌표로 변환된 2D 컨텍스트다. `ctx.save()/restore()`로 투명도·클립을 감싼다.

## 4. 색 의미

색은 장식이 아니라 정보로 쓴다. 한 페이지 안에서 일관되게 유지한다.
- `C.copper`: 열·고온·업스트림. 온도는 `mixc('#1b2130','#c2551f',T/1100)`처럼 어두운 색에서 주황으로 보간한다.
- `C.lilac`: 다운스트림·강조·자기장·진행 중인 대상
- `C.amber`: 첨가물·코팅·확산원처럼 "덧붙는 재료"
- `C.steel`: 설비 외곽선. 금속 제품은 `metalGrad`
- `C.N` / `C.S`: 자극처럼 대립하는 두 상태

## 5. 장면 패턴과 예제 위치

예제 파일: `references/example-ndfeb/scenes.js`

| 패턴 | 언제 | 예제 (주석 머리) |
|---|---|---|
| 지형·원료 + 확대 인셋 | 원료 채굴, 원재료 소개 | `1. 채광` (돋보기 원 안에 결정 구조) |
| 설비 + 물질 흐름 + 더미 증가 | 분쇄, 선별, 이송 | `2. 분쇄·선광` (롤러, 컨베이어, 기포, 정광 더미) |
| 단계 칩 ①②③ + 상태 변화 | 한 장면 안 하위 공정 3개 | `3. 침출·침전`, `11. 로터 조립·착자` |
| 경로를 따라 갈라지는 흐름 | 분리·분급 | `4. 분리·정제` (`along`으로 종류별 경로) |
| 발광·전극·적하·주형 채움 | 용융, 전해, 주조 | `5. 금속 환원`, `6. 합금·스트립캐스팅` |
| 로그 눈금 크기 막대 | 입도·두께 변화 | `7. 수소파쇄·미분쇄` (μm 로그 축 위 표식) |
| 정렬·가압 | 성형, 배향 | `8. 자장 중 성형` |
| 설비 + 공정 그래프 | 열처리 프로파일 | `9. 소결·열처리` (온도 곡선을 t까지 그림) |
| 단계 내 교차 페이드 | 한 단계에 하위 화면 여러 개 | `10. 가공·입계확산·코팅` (A/B/C 단계 alpha) |
| **분할 화면 비교** | 설비 방식 A vs B | `9B. 소결로 방식 비교` |
| **2×2 방식 격자** | 방법 4가지 비교 | `10B. 입계확산 도포 방식` (활성 패널 강조, `clip`) |
| **3×2 타일** | 종류 6가지 + 한 줄 장단점 | `10C. 표면 코팅 종류` |
| 요약 아이콘 체인 | 마지막 장면 | `12. 요약` (형태 아이콘 11개, 두 줄 배치) |

비교 장면 공통 규칙:
- 활성 패널은 `t*패널수`로 차례로 강조(테두리 `C.lilac`, 내용 alpha 1)하고 나머지는 alpha 0.55로 둔다.
- 패널 내부 애니메이션은 `ctx.save(); rr(...); ctx.clip();`으로 패널 밖에 넘치지 않게 한다.
- 장단점은 `+ …` / `− …` 한 줄씩(15–16px)으로 짧게 쓰고, 자세한 내용은 페이지 비교표로 넘긴다.

## 6. 자주 하는 실수

- 라벨끼리 또는 라벨과 그림이 겹친다. `callout`의 글자 방향과 길이를 계산해서 빈 공간 쪽으로 뺀다.
- 기울어지거나 회전하는 설비(도가니 기울임 등)가 위쪽 라벨을 덮는다. 회전 후 꼭짓점 위치를 계산해 본다.
- 이미 나온 라벨이 장면 끝에서 사라져 정지 화면이 허전하다. 사라지는 라벨은 다음 하위 단계 라벨로 대체한다.
- 공정 순서가 실제와 다르다(예: 착자 → 조립). 장면 순서와 하위 단계 칩을 실제 산업 순서로 맞춘다.
- 모든 장면이 같은 구도다. 흐름형, 단면형, 그래프형, 비교형을 섞어 단계마다 핵심 정보에 맞는 시각화를 고른다.
